# 六款進階遊戲 — v0.2.0

這是可實際作答的親子試玩擴充。完整音節、聲調與詞語使用固定題庫和預製臺灣華語合成音；未完成教學者雙人聽校及幼兒真機驗證，不宣稱正式教育驗收完成。

## 題庫與教學

12 個圖卡詞語：貓（ㄇㄠ）、雞（ㄐㄧ）、瓜（ㄍㄨㄚ）、花（ㄏㄨㄚ）、魚（ㄩˊ）、牛（ㄋㄧㄡˊ）、球（ㄑㄧㄡˊ）、馬（ㄇㄚˇ）、狗（ㄍㄡˇ）、兔（ㄊㄨˋ）、樹（ㄕㄨˋ）、豆（ㄉㄡˋ）。每個完整讀音有獨立音檔；不以單符號音檔拼接成完整音節。

題庫同時檢查「注音已引入」與「詞語已聽過／家長確認已教」。小教室在完整播放成功後才引入詞語；換頁或播放失敗不能算已聽過。家長可逐詞取消勾選，亦可確認 12 詞都已教；勾選不是精熟評分。

聲調以「湯、糖、躺、燙」的 ㄊㄤ 音節提供四聲對比。較高難度聽兩個完整音節，再依序選聲調；詞語末音題使用香蕉（一聲）、紅茶（二聲）、小狗（三聲）、白兔（四聲）、帽子（輕聲）。避免把可有輕聲變讀的「葡萄」作二聲唯一答案。家長或小教室須先引入對應聲調。所有詞語涉及的符號仍須已引入。

依教育部《國語注音符號手冊》，一聲省略調號；二、三、四聲顯示於音節尾部右上方；輕聲不當作固定第五種音高曲線。氣球中的路徑僅作單獨音節的初學示意，不宣稱連續語流保持相同曲線。題目只播音、不顯示正解的聲調符號。

## 遊戲與四階難度

| 遊戲         | 低階 → 高階                                       | 答案規則                                                                                                           |
| ------------ | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 拼音小火車   | 兩符號一聲 → 兩符號四聲 → 三符號 → 拼音後選聲調   | 依序填入核定音節；錯答保留已填前綴。干擾項只用已引入符號，聲調選擇在最後一格獨立出現                               |
| 聲調氣球     | 一／四聲 → 四聲 → 兩聲依序選 → 詞語末音含輕聲     | 固定語音素材與聲調資料一對一；不根據音訊臨時猜答案。聲調順序必須正確                                               |
| 缺字小偵探   | 最後一格缺字 → 任一格 → 三符號 → 修正錯字         | 空格或問號框有且僅有一個正解；錯字必與正解不同，修正後才顯示完整核定拼音                                           |
| 注音小商店   | 三圖一商品 → 六圖一商品 → 六圖兩商品 → 九圖三商品 | 訂單、商品及選取順序一致；商品不重複。一般指令不讀出商品；提示讀出目前商品後記為協助                               |
| 聲音翻翻樂   | 四張符號／聲音 → 六張 → 八張 → 八張圖片／詞音     | 每對一張視覺卡、一張聲音卡；同張、已配對及第三張牌不能重複操作。語音說完再開放下一次翻牌                           |
| 注音尋寶地圖 | 一步四方向 → 兩步 → 三步 → 三步八方向             | 九格符號唯一；小兔由中央開始，每一步相鄰且不越界。分段模式走完一步才念下一步，整段模式先念全部；途中不能重新洗地圖 |

所有難度只使用足夠且已教的題庫；不夠時顯示具體需求與教學入口。六款都支援觸控點選、滑鼠與鍵盤，不要求拖曳、識字、錄音或登入。

## 回合、提示及紀錄

- 與既有遊戲共用家長的 5／10／15／20／30 題設定；開始回合時取得固定題數。翻翻樂每題代表一整組配對。
- 一級提示重播題目，小商店則讀出目前商品；二級標示當前正解或翻牌內容；三級列為一起練習。提示與重聽不灌入獨立完成。
- 完成一回合只發一張小花貼紙。每題先存中斷占位，再以完成結果覆寫；重複完成不灌分。記錄題種、難度、模式、步數、提示、重聽、錯答、種子與回合 ID。
- 切換 App／失焦或主動暫停會停語音；回來從本題第一步重做，已完成題目保留，本題不列獨立。頁面重載保留已存學習紀錄，活動回合不自動續玩。
- 狀態包括準備語音、可作答、回饋、已完成、翻牌未配對、暫停及音檔錯誤。音檔失敗可重試或略過，不能卡住為永遠可作答的假狀態。
- 統計各遊戲分開，仍排除中斷；最多保留最近 1,000 題。家長設定、匯出及清除涵蓋新欄位；舊版紀錄保留原題數與歷史，新增引入欄位為空陣列。

## 素材、離線及發布

47 個新音檔的臺詞與 SHA-256 在 `public/audio/advanced/texts.json`。`scripts/generate-advanced-audio.py` 是建置前使用的工具，不在幼兒瀏覽器執行；只送固定臺詞，音檔下載後不再依賴外部語音服務。所有新音檔皆納入離線清單與 SHA-256 驗證。12 張圖卡為本專案原創 SVG；維持官方注音字形與 Noto TC 字型。

程式模組：`src/data/advanced.ts`（固定資料）、`src/core/advanced-rules.ts`（生成與判定）、`src/components/AdvancedGames.tsx`（教學與實際回合）、`src/components/WordArt.tsx`（圖卡）、`src/components/ui.tsx`（共用元件）、`src/advanced.css`（手機／平板版面）。前四款遊戲及原有 Pages 路徑保留。

規則測試覆蓋六款×四難度×1,000 種子，共 24,000 道新題，另含順序、配對、題庫門檻、舊紀錄與不重複記分。瀏覽器測試涵蓋最高難度實際作答、完整回合、教學成功、暫停、家長題數、窄手機及 WCAG AA 自動檢查；自動檢查不能代替人工聽校與真機測試。
